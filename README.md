# Skrattlådan

Partyspel för två personer i webbläsaren. Tre minispel i rotation:

1. **Fyll i luckan** – absurd mening med ett hål i; båda skriver i smyg, avslöjas samtidigt, sen sätter ni skrattbetyg på varandra.
2. **Kluddgissning** – en ritar live, den andra gissar medan pennan går.
3. **Förbjudna ord** – beskriv ordet utan att använda de fem spärrade orden; motståndaren ser varje bokstav i realtid.

Ingen server, ingen databas, inget konto. Spelarna kopplas direkt till varandra
med WebRTC (PeerJS publika broker sköter bara första handskakningen).
Allt ligger i `index.html`.

**Spela:** https://uselesspianoman.github.io/skrattladan/
